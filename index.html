Change password

Changes the password for whichever username you're currently signed in as — it only gates this page in this specific browser, it's a light deterrent, not real security (the GitHub token above is the actual permission check). The new password is stored only on this device; it isn't sent anywhere, so no one else — including whoever built this page — can see or recover it. If it's ever forgotten on a device, use the "Forgot password?" link on the login screen to reset just that username back to its original default password.
